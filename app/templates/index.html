Personal Finance Companion

结合当前财务档案、历史决策与市场数据，辅助持续的个人金融规划。

当前阶段：T03 模拟行情与本地缓存

已实现 SP/CA 存储、候选变更确认、显式数据库迁移，以及 MD 的 Python 服务与 CLI 缓存读取和刷新。

目前仅有明确标注的固定虚构股票价格、基金净值和指数点位，缓存新鲜不代表实时行情。

摘要由明确的服务调用写入。业务 HTTP 接口、交互页面、真实行情与模型 API、自动摘要和目标 Dashboard 尚未实现。

模块职责

SP · 结构化财务档案
保存当前已确认的预算、持仓、目标和偏好，表示当前有效状态。
CA · 对话档案
保存原始聊天、会话摘要和历史重要决策概览 CA Overview，解释历史变化。
MD · 市场数据
保存经过规范化、有明确来源和时间的市场数据。

后续每轮默认提供精简 SP、CA Overview 和近期消息；详细历史与行情由后端工具按需读取。

当前技术路线使用本地 SQLite，不使用 RAG、Embedding 或向量数据库。
